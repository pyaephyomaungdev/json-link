# JSON Link Vite i18n Integration Skill

This skill guides AI agents and developers on how to seamlessly integrate translations managed in **JSON Link** into any React + Vite application with compile-time type safety, zero external library overhead, and instant Vite Hot Module Replacement (HMR).

---

## Core Principles

1. **Zero-Daemon, Zero-Overhead**: No local watch daemons or Swagger/API servers. The integration relies strictly on static JSON bundles and Vite's native module bundler.
2. **Compile-Time Type Safety**: Keys are strongly typed via `translations.d.ts` so developers get full IDE autocomplete and compile-time detection of typos or deleted keys.
3. **Drop-in First**: Prioritize dropping `/src/locales/` into the developer's existing repository over forcing them to clone an entire boilerplate app.
4. **Token & ICU Preservation**: Interpolation preserves `{variable}` and Mustache tokens without mangling formatting or punctuation.

---

## Architecture: The 3-File Setup

When exported from JSON Link as a Vite Starter, the translation bundle resides in `src/locales/`:

```
src/
└── locales/
    ├── en.json              # Source language dictionary
    ├── my.json              # Target language dictionary (Myanmar, etc.)
    ├── translations.d.ts    # Autogenerated TypeScript definitions
    └── i18n.ts              # Reactive client loader (< 50 lines, 0 dependencies)
```

### 1. `translations.d.ts` (Type Definitions)
Defines the `SupportedLanguage` and `TranslationKey` string unions based on all keys currently in the spreadsheet.

```typescript
export type SupportedLanguage = "en" | "my";

export type TranslationKey =
  | "app.title"
  | "auth.welcome"
  | "common.cancel";

export interface TranslationDictionary {
  [key: TranslationKey]: string;
}

export type I18nResources = {
  [lang in SupportedLanguage]: Record<TranslationKey, string>;
};
```

### 2. `i18n.ts` (Reactive Client Loader)
A clean, zero-dependency client loader that exposes:
- `t(key, params?, lang?)`: Core translation function with `{param}` interpolation and dotted key traversal (`auth.login.title`).
- `setLanguage(lang)`: Global active language updater.
- `useTranslation()`: React hook for functional components.
- `import.meta.hot.accept()`: Native Vite HMR listener that updates text on the screen without full page reloads.

## Agent Integration Recipes

### Recipe 1: Dropping into an Existing React + Vite Project

When asked to add localization or connect JSON Link to an existing React project:

1. **Verify or create `src/locales/`**:
   Ensure `src/locales/` exists and contains the exported `.json` files and `i18n.ts`.

2. **Verify `tsconfig.json`**:
   Ensure `resolveJsonModule` is enabled:
   ```json
   {
     "compilerOptions": {
       "resolveJsonModule": true
     }
   }
   ```

3. **Wire up in React components (3 lines)**:
   ```tsx
   import { useTranslation } from './locales/i18n';

   export function NavigationBar() {
     const { t, language, setLanguage, languages } = useTranslation();

     return (
       <nav>
         <span>{t('app.title')}</span>
         <select
           value={language}
           onChange={(e) => setLanguage(e.target.value as any)}
         >
           {languages.map((lang) => (
             <option key={lang} value={lang}>
               {lang.toUpperCase()}
             </option>
           ))}
         </select>
       </nav>
     );
   }
   ```

### Recipe 2: Handling Interpolated Variables

For translation strings containing dynamic variables like `Welcome back, {username}!`:

```tsx
// In locale JSON: { "auth.welcome": "Welcome back, {username}!" }
const { t } = useTranslation();
<p>{t('auth.welcome', { username: user.name })}</p>
```

### Recipe 3: Updating / Syncing Locales

When new translation strings are added or updated in JSON Link:
1. Export updated JSON files from JSON Link (or export the Vite Starter ZIP).
2. Overwrite files in `src/locales/`.
3. Vite HMR will immediately refresh the copy in active browser tabs with zero server restarts.

### Recipe 4: Mounting the `<JsonLinkDevtools />` Drawer for In-App Live Copy Tweaking

When developers or QA want to inspect, search, and tweak copy directly inside their running Vite app without touching source files:

1. **Mount `<JsonLinkDevtools />` in your root `App.tsx` or layout**:
   ```tsx
   import { JsonLinkDevtools } from './locales/devtools';

   export default function App() {
     return (
       <div>
         <MainContent />
         {/* Devtools Drawer for live in-app inspection */}
         {import.meta.env.DEV && <JsonLinkDevtools />}
       </div>
     );
   }
   ```

2. **In-Browser Inspection & Tweaking**:
   - Click the floating **⚡ JSON Link Devtools** button in the bottom corner.
   - Filter translation keys by key name or copy content in real time.
   - Switch language tabs (e.g. `EN`, `MY`, `JA`) to review translations side-by-side.
   - Edit any string in the textarea: `updateTranslation()` updates the in-memory dictionary and dispatches to `useTranslation()` subscribers, immediately re-rendering the running app's UI.
   - Click **📋 Copy JSON** or **💾 Save JSON** to export updated dictionaries back into your project.
